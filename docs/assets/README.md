# Brand assets

| File | Size | Use |
|------|------|-----|
| `social-card.png` | 1280×640 | GitHub social preview (Settings → General → Social preview) and link-share cards |
| `icon.png` | 1024×1024 | Icon master |
| `icon-512.png` / `icon-256.png` | 512 / 256 | Org/repo avatar, general use |
| `apple-touch-icon.png` | 180×180 | iOS home-screen icon |
| `icon-64.png` / `icon-32.png` / `icon-16.png` | 64 / 32 / 16 | Favicon sizes |

The mark is a solid "C" whose data-facing edge crystallizes from sharp shards melding white → teal → blue → indigo, matching the wordmark card. Background is `#0a0f1a`.

Manual steps (outside the repo): upload `social-card.png` under the repo's Settings → Social preview, and set the org/repo avatar to `icon-512.png`.
